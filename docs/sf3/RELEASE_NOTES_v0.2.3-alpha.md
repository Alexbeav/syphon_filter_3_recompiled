# Syphon Filter 3 Recompiled v0.2.3-alpha

This prerelease keeps the accepted v0.2.2 widescreen, mouse-look, PGXP
component-provenance and precise-culling implementation and streamlines the
legal owned-input build.

## Player setup

- Double-click `SETUP.cmd` with the legally obtained USA SCUS-94640 BIN/CUE
  files beside the extracted kit.
- Missing Python and WinLibs GCC/CMake/Ninja tools are downloaded as pinned,
  SHA-256-verified portable archives inside the kit.
- WinGet, Git, pip, Visual Studio and system-wide installation are not needed.
- Setup writes a redaction-warned log and creates `PLAY_SF3.cmd` after the
  private local build succeeds.
- Existing compatible tools are reused, and advanced users retain explicit
  CUE, output, compiler and build-job controls.

The archive contains no retail executable, disc data, generated game code,
save data, capture or private third-party artifact. The player must provide a
legally obtained USA SCUS-94640 dump; its extracted executable is hash-gated
before compilation. PSXRecomp remains PolyForm Noncommercial 1.0.0.
