# Syphon Filter 3 Recompiled v0.2.2-alpha

This noncommercial owned-input release adds the human-accepted PGXP geometry
path for the USA `SCUS-94640` release.

Included:

- authentic retail execution through PSXRecomp and bundled MIT OpenBIOS;
- 4× OpenGL rendering and native 16:9 world presentation;
- PGXP vertex provenance across the proven GTE, CPU and packet paths;
- perspective-correct texture coordinates and shared-edge reconciliation;
- exact-FIFO precise polygon culling;
- direct mouse camera/aim, keyboard controls, mouse buttons and weapon wheel;
- a hash-pinned generator that compiles the private game executable locally.

Human testing accepts the result as shippable: the dominant motion wobble and
polygon disappearance are removed. Minor texture wobble and visible character
model seams remain. HUD elements remain inset at their original 4:3 positions,
and campaign validation currently reaches Mission 4 rather than the complete
campaign.

The download contains no Syphon Filter 3 executable, disc data, generated game
code, overlay cache, saves, cards, screenshots, movies, audio or other retail
assets. Supply a legally obtained USA BIN/CUE dump. The bootstrap verifies
`SCUS_946.40` before compilation. Generated sources and binaries must remain
private.

Local compilation requires Python 3, CMake, Ninja and a C/C++ compiler and can
take several minutes.
